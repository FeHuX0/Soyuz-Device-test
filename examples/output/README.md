# Результаты генерации примеров

В каталоге сохранены результаты генерации карточек (JSON и Markdown) для двух входных примеров:

- `product_1.json` и `product_1.md` — полный пример манометра `DM 02` (`examples/product_1.json`) со всеми исходными характеристиками и вопросами на уточнение условий эксплуатации.
- `product_2.json` и `product_2.md` — неполный пример термопреобразователя `ТСМ-50` (`examples/product_2.json`) с пометками `«данных нет»` для отсутствующих обязательных характеристик (`Диапазон измерений`, `Точность / погрешность`) и предупреждениями для контент-менеджера.

Оба примера прошли строгую контекстную валидацию Pydantic (`ProductCard` и `check_card_grounding`), а Markdown-версии сформированы единым рендерером `src/render.py`.
